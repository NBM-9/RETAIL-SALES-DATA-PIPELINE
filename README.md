# RETAIL-SALES-DATA-PIPELINE

## Project Overview
This project demonstrates a basic data engineering pipeline where raw retail sales data is cleaned and prepared for analysis.

## Data Description
The dataset contains retail sales transactions including:
- Order ID
- Order Date
- Customer ID
- Product
- Category
- Quantity
- Sales amount

## Data Issues in Raw Data
- Duplicate records
- Missing values
- Inconsistent formatting

## Data Processing Steps
1. Loaded raw CSV data using Python
2. Standardized column names
3. Removed duplicate records
4. Removed rows with missing values
5. Converted date fields to proper format
6. Saved cleaned data for analytics use

## Tools Used
- Python
- Pandas

## Outcome
A clean, structured dataset ready for SQL analysis or data warehousing.
